# Desenvolvimento de Interfaces Web

## Sobre
Materiais da disciplina **Desenvolvimento de Interfaces Web**, por ano. Conteúdo:
- **Front-end estático**: HTML, CSS, JavaScript (vanilla)
- Bootstrap, Font Awesome; no trabalho prático, Mapbox GL
- Sem backend nem bundler

## Objetivo
- Desenvolver interfaces web responsivas e interativas
- Projetos semanais (1 a 9) + trabalho prático (projeto 10 — portal de álbuns geolocalizados)

## Estrutura do projeto
- **`2023/`** — pasta do ano (única presente)
  - **`projetos/`** — projeto 1 (primeiro site) a projeto 9 (js 3); cada um com `index.html`, CSS, JS quando aplicável
  - **`trabalho-pratico/`** — projeto 10: `projeto 10/` (album.html, map.js, estilos, imagens, etc.) + `README.md`
- **`2023/README.md`** — descrição de cada projeto e como rodar

## Tecnologias
- **HTML**, **CSS**, **JavaScript**
- **Bootstrap**, **Font Awesome**
- **Mapbox GL** (trabalho prático / projeto 10)

## Como executar
- **Projetos 1 a 9:** abra o `index.html` da pasta do projeto no navegador (ou use servidor local).
- **Projeto 10:** exige token Mapbox; use servidor local. Veja `2023/trabalho-pratico/README.md`.
