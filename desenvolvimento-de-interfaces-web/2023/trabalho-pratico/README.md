# Trabalho Prático — Portal de Álbuns Geolocalizados (2023)

Projeto final da disciplina **Desenvolvimento de Interfaces Web**: portal estático com **HTML**, **CSS**, **JavaScript**, **Bootstrap 5** e **Mapbox GL** para álbuns de viagens e museus com mapa.

## Conteúdo

A pasta **`projeto 10/`** contém:

- **Páginas:** `index.html` (inicial com carrossel e mapa), `meus-albuns.html`, `album.html`.
- **Scripts:** `carrossel.js`, `card.js`, `modal.js`, `meus-albuns.js`, `album.js`, `salvo.js`, `offline.js`, `map.js` (Mapbox).
- **Recursos:** skip-link, ARIA, navbar responsiva, mapa Mapbox; carrossel com dados locais ou API; `config.example.js` para chaves/URLs.

## Como usar

Abra os arquivos `.html` no navegador (ou use um servidor local para evitar CORS). Configure a URL da API e a chave Mapbox em `config.example.js` (ou no arquivo de configuração usado pelo projeto).

Ver o **README principal** da disciplina em `desenvolvimento-de-interfaces-web/2023/README.md` para a estrutura completa dos projetos.
