# Arquitetura de Computadores

## Sobre
Materiais da disciplina **Arquitetura de Computadores**, por ano. Conteúdo:
- **Circuitos digitais** para simuladores (Logisim e Construtor Virtual)
- Sem código em linguagem de programação

## Objetivo
- Projetar e simular circuitos digitais
- Entregas em formato de circuitos (`.circ`, `.txt`) para os simuladores

## Estrutura do projeto
- **`2022/`** — pasta do ano (única presente)
  - **`logisim/`** — Relatório 1.circ, Relatório 2.circ, Relatório 3.circ, Relatório 4.circ
  - **`construtor-virtual-097/`** — Circuito 1.txt a Circuito 12.txt
- **`2022/README.md`** — instruções, tecnologias e uso dos circuitos

## Tecnologias
- **Logisim** ou **Logisim Evolution** — arquivos `.circ`
- **Construtor Virtual de Circuitos** (versão 0.9.7) — arquivos `.txt`

## Como executar
- **Logisim:** abra os `.circ` em [Logisim](http://www.cburch.com/logisim/) ou [Logisim Evolution](https://github.com/logisim-evolution/logisim-evolution).
- **Construtor Virtual:** abra os `.txt` no Construtor Virtual 0.9.7 (ou compatível).

Instalação e detalhes em `2022/README.md`.
