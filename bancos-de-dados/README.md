# Bancos de Dados

## Sobre
Materiais da disciplina **Bancos de Dados**, por ano. Conteúdo:
- **SQL**: DDL, DML, consultas
- **PostgreSQL** (listas) e **Microsoft SQL Server** (trabalho prático)

## Objetivo
- Praticar modelagem e consultas SQL
- Listas no PostgreSQL (modelo veículo/proprietário); trabalho prático (Jogos Olímpicos) no SQL Server

## Estrutura do projeto
- **`2024/`** — pasta do ano (única presente)
  - **`listas/`** — PostgreSQL: `schema_veiculo_proprietario.sql`, `lista6.sql`, `lista7.sql`, `lista8.sql`
  - **`trabalho-pratico/`** — SQL Server: `criacao_banco_tabelas.sql`, `indices_views.sql`, `consultas_olimpiadas.sql`
- **`2024/README.md`** — ordem de execução dos scripts e requisitos

## Tecnologias
- **PostgreSQL**
- **Microsoft SQL Server**

## Como executar
- Leia `2024/README.md` para a ordem dos scripts.
- **Listas (PostgreSQL):** execute o schema, depois as listas 6, 7 e 8.
- **Trabalho prático (SQL Server):** execute criação do banco e tabelas → índices/views → consultas.
